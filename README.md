# Mac Utils

Нативная утилита для macOS (SwiftUI + AppKit), которая живёт в строке меню и показывает:

- **сведения об интернет-соединении**: флаг страны, через которую трафик выходит в интернет, и текущую скорость приёма и отдачи;
- **виджет на рабочем столе**: загрузка CPU, RAM и диска в реальном времени.

Иконки в Dock у приложения нет (это agent app, `LSUIElement`). Интерфейс на русском и английском, язык выбирается по языку системы.

## Строка меню

```
🇳🇱 ↑  12 KB/s
    ↓ 1.4 MB/s
```

- **Флаг** показывает страну публичного IP-адреса. При включённом VPN это страна VPN-сервера. Пока страна неизвестна (нет сети или сервис недоступен), вместо флага стоит значок глобуса.
- **Скорость**: две строки друг над другом, отдача (↑) и приём (↓). Ширина элемента фиксированная, поэтому соседние значки в строке меню не прыгают.
- Считается трафик физических интерфейсов (Ethernet, Wi-Fi, USB-модем). Туннельные интерфейсы VPN (`utun`, `ipsec`, `ppp`) не суммируются, иначе один и тот же трафик посчитался бы дважды.

**Клик левой кнопкой** открывает панель с подробностями:

| Раздел | Что показано |
|---|---|
| Местоположение | Страна, регион, город, часовой пояс |
| Внешний IP и провайдер | Публичный IP (копируется кнопкой), провайдер, ASN |
| Локальная сеть | Активный интерфейс (Wi-Fi, Ethernet…), локальный IP, состояние VPN и туннельный интерфейс |
| Трафик | Текущая скорость, график за последнюю минуту, принято и отправлено с момента запуска |

Внизу панели: время последнего обновления, кнопка «Обновить», переключатель виджета, «Настройки…» (⌘,) и «Выйти» (⌘Q).
**Клик правой кнопкой** открывает короткое меню: «Настройки…» и «Выйти».

### Как определяется страна

Страну можно узнать только по публичному IP, поэтому приложение обращается к бесплатному сервису геолокации по HTTPS. Основной сервис [ipinfo.io](https://ipinfo.io), запасной [ipwho.is](https://ipwho.is), API-ключ не нужен. Запрос отправляется:

- при запуске и при выходе Mac из сна;
- при смене сети, то есть когда меняется набор интерфейсов или адресов (например, включили или выключили VPN);
- периодически, интервал задаётся в настройках (по умолчанию 5 минут);
- вручную, кнопкой «Обновить».

Сервис видит ваш публичный IP-адрес. Больше никакие данные с компьютера не уходят.

## Виджет на рабочем столе

Это прозрачное окно без рамки на уровне рабочего стола: оно лежит под обычными окнами, видно на всех Spaces и не исчезает при «Показать рабочий стол». WidgetKit не используется, потому что системные виджеты обновляются раз в несколько минут, а здесь нужно реальное время.

| Блок | Метрики |
|---|---|
| **CPU** | Общая загрузка (user/system), загрузка каждого ядра с пометкой E/P (энергоэффективные и производительные ядра Apple Silicon), температура кристалла SoC, средняя нагрузка (load average) |
| **Память** | Использованная память так же, как её считает Мониторинг системы (app + wired + compressed), объём, swap, давление памяти |
| **Диск** | Занято и свободно на выбранном томе, скорость чтения и записи, температура SSD |

Температура показывается в единицах вашего региона (°C или °F).

Виджет можно **перетащить курсором** в любое место, в том числе на другой монитор. Он останется там, где его отпустили, и не уйдёт за край экрана. Если виджет был привязан к углу, после перетаскивания положение переключается на «Где угодно». Чтобы случайно не сдвинуть виджет, включите «Закрепить положение».

Правый клик по виджету открывает меню: закрепить или открепить положение, настройки виджета, скрыть виджет.

## Настройки

Окно настроек (⌘,) состоит из трёх вкладок:

- **Основные**: запуск при входе в систему, единицы скорости (байты: КБ/с, МБ/с; биты: Кбит/с, Мбит/с).
- **Строка меню**: показывать флаг, показывать скорость, частота обновления местоположения.
- **Виджет**:
  - показать или скрыть виджет, частота обновления от 0,5 до 5 с;
  - видимость блоков CPU, «Память», «Диск» и метрик внутри них (ядра, температура, load average, swap, давление памяти, выбор тома, скорость чтения и записи, температура SSD);
  - внешний вид: размер (компактный или обычный), тема (системная, светлая, тёмная), непрозрачность фона;
  - положение: «Где угодно» (куда перетащили) или привязка к углу экрана, выбор монитора, закрепление на месте, сброс положения.

Настройки хранятся в `UserDefaults` (`com.iburimskiy.MacUtils`).

## Источники данных

| Метрика | API |
|---|---|
| Сетевой трафик | `sysctl(NET_RT_IFLIST2)`, 64-битные счётчики `if_data64` |
| Интерфейсы, IP, VPN | `getifaddrs`, `SystemConfiguration` (основной интерфейс, имена интерфейсов) |
| Загрузка CPU по ядрам | `host_processor_info(PROCESSOR_CPU_LOAD_INFO)` |
| Типы ядер E/P | IORegistry `IODeviceTree:/cpus/*` → `cluster-type` |
| Температура | HID-датчики `IOHIDEventSystemClient` (`PMU tdie*`, `NAND`) |
| Память | `host_statistics64(HOST_VM_INFO64)`, `vm.swapusage`, `kern.memorystatus_vm_pressure_level` |
| Место на диске | `URLResourceValues` (`volumeAvailableCapacityForImportantUsage`, это то же значение, что показывает Finder) |
| Чтение и запись диска | IOKit `IOBlockStorageDriver` → `Statistics` |

Температура читается через закрытое API IOKit, поэтому приложение собирается **без песочницы** и не подходит для Mac App Store. Права администратора не нужны. На Mac с Intel этих датчиков нет, и температура не показывается.

## Требования

- macOS 14 Sonoma или новее, Apple Silicon или Intel;
- для сборки нужны Xcode 16+ и [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

## Сборка и запуск

```sh
make run        # сгенерировать проект, собрать Release и запустить
make install    # собрать и скопировать в /Applications
make project    # только сгенерировать MacUtils.xcodeproj, чтобы открыть его в Xcode
make clean
```

Сборка подписывается ad-hoc (`codesign -`). Чтобы запуск при входе работал надёжно, установите приложение в `/Applications` (`make install`).

### Проверка интерфейса без доступа к записи экрана

Debug-сборка умеет сохранять PNG-снимки собственных окон (виджет, элемент строки меню, панель, все вкладки настроек). Разрешение «Запись экрана» для этого не нужно:

```sh
make build CONFIG=Debug
build/Build/Products/Debug/MacUtils.app/Contents/MacOS/MacUtils -snapshotDir /tmp/macutils-snapshots
# язык интерфейса можно переопределить: -AppleLanguages '(en)'
```

## Ограничения

- Название сети Wi-Fi (SSID) не показывается: на macOS 14+ для этого нужен доступ к геолокации.
- Скорость диска считается суммарно по всем блочным устройствам, включая подключённые образы `.dmg`.
- Если включён VPN с раздельным туннелированием (split tunnel), страна определяется по маршруту, которым идут запросы к сервису геолокации.
